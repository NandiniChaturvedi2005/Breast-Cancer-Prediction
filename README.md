# Breast-Cancer-Prediction
Breast Cancer Prediction System using Machine Learning and an Interactive AI Chatbot. Built with Python, Scikit-learn, Google Colab, and Gradio.

Project Overview

This project uses Machine Learning to predict whether a breast tumor is benign or malignant based on medical parameters. The project also includes an AI-powered chatbot that answers basic breast cancer-related questions and provides guidance to users.

Features

Breast Cancer Prediction using Logistic Regression
Interactive User Interface using Gradio
AI Healthcare Chatbot
Patient-Friendly Guidance Messages
Real-Time Predictions

Technologies Used

Python
Scikit-Learn
Pandas
NumPy
Gradio
Google Colab
